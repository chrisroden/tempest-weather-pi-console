# Tempest Weather Pi Console

Tempest Weather Pi Console includes:

- A Raspberry Pi desktop UI built with Avalonia (`Tempest.UI`)
- A Blazor web app (`TempestBlazorApp`)
- Shared REST and WebSocket components
